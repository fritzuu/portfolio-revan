# Revan Zhafran - Personal Portfolio

A modern, responsive, and aesthetically pleasing personal portfolio website built with React and Vite. It showcases my skills, experience, projects, and certificates with a clean UI and smooth animations.

## 🚀 Features

- **Dark & Light Mode**: Built-in theme switcher with persistent state (saves to local storage).
- **Fully Responsive**: Optimized for desktop, tablet, and mobile devices. 
- **Smooth Animations**: Powered by Framer Motion for scroll reveals, typing effects, and page transitions.
- **Dynamic Navigation**: Centered pill navigation on desktop, and a sleek bottom/drawer menu on mobile.
- **WhatsApp Integration**: Contact form redirects directly to WhatsApp with pre-filled messages.
- **Glassmorphism Design**: Modern UI with blurred backdrops and subtle ambient glows.

## 🛠 Tech Stack

- **Framework**: React (Vite)
- **Styling**: Vanilla CSS with CSS Variables for Theming
- **Animations**: Framer Motion
- **Icons**: Google Material Symbols
- **Fonts**: Plus Jakarta Sans, Inter, JetBrains Mono

## 💻 Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/fritzuu/portfolio-revan.git
   cd portfolio-revan
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```

## 📂 Project Structure

- `src/components/`: Contains all UI sections (Hero, About, Projects, Navbar, etc.).
- `src/context/`: Context providers (e.g., `ThemeContext.jsx` for Dark/Light mode).
- `src/index.css`: Global styles, CSS variables, and responsive breakpoints.
- `src/App.jsx`: Main application layout and routing.
